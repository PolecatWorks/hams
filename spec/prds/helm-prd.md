# helm/ PRD

Overview: helm/ contains Helm charts or Kubernetes deployment artifacts used to deploy components for demo or production use.

Goals:
- Provide templated Helm charts for demo deployments.
- Ensure charts are versioned and documented; include values.yaml with examples.
- Add CI linting for charts and optional packaging to Artifact Hub.

Acceptance Criteria:
- Charts lint in CI and example deploy manifests provided.

PRD version: 0.1
